IMPLEMENTATION

纯前端、多图表、可离线运行

作品采用静态网页方式实现，核心数据以 JSON/GeoJSON 组织，图表、地图和3D模型由前端渲染；AI助手在联网时调用DeepSeek API，并先注入本地检索上下文，便于离线访问、现场演示和本地部署。

Layer 01
数据整理
文献、文物资料和桥梁条目清洗为统一字段。
Layer 02
数据服务
JSON、GeoJSON、图片、音频与检索上下文作为本地资源加载。
Layer 03
可视化渲染
ECharts 绘制图表，地图点位与筛选联动。
Layer 04
三维与动效
Three.js 桥梁建模与 CSS 动效增强桥型展示和页面层次。
Layer 05
AI与语音
DeepSeek API、讯飞 TTS、本地 MP3 与浏览器朗读协同兜底。
技术选择服务于传播目标：核心内容无需后端即可运行；同时通过地图、图表、3D、音频和联网AI提升文化遗产内容的可感知性。TECHNICAL PRINCIPLE
HTML5 · CSS3 · JavaScript · ECharts · Three.js · GeoJSON · DeepSeek API
